% Values the manuscript cannot compute: they come from outside the artifacts and outside the
% code. Each renders as a conspicuous bracket so it cannot survive to submission unnoticed, and
% each is defined in exactly one place so filling it is a one-line edit. This file is shared by
% every journal wrapper, because a marker that lives in a layout preamble goes missing the moment
% the target journal changes -- which is how \ZenodoDoi came to be undefined.
\newcommand{\unresolved}[1]{\textbf{[#1]}}
% The bracket has to break across a two-column line, so it carries explicit break points.
\newcommand{\ZenodoDoi}{\unresolved{ZENODO DOI}}

% terms and does not resolve. What follows from it for this deposit is a release decision
% and is taken rather than deferred: no source structure is redistributed.
\newcommand{\CorpusLicence}{settled by not redistributing them: the deposit carries no source structure}
